# Citation map: repealed law to current law

Applied 2026-09-16 by `tools/migrate_citations.py`, to `api/seed/clauses.json` and the live database. Every row below is generated from that script, so this page and the data cannot drift apart.

## Why

| Old text | Status today | Evidence |
|---|---|---|
| Mines Act, 1952 | Repealed | OSH Code 2020 s.143(1)(c); Code in force 21 Nov 2025 |
| Mines Rules, 1955 | Superseded | OSH (Central) Rules 2026, G.S.R. 345(E), 8 May 2026 |
| Mines Rescue Rules, 1985 | Superseded | OSH (Central) Rules 2026 |
| Coal Mines Regulations, 2017 | In force | Saved by OSH Code s.143(3) |

Sources and checksums: [data/SOURCES.md](../data/SOURCES.md).

## What changed in substance, not just in citation

| Duty | Before | Now |
|---|---|---|
| Safety Committee | 100+ workers | 500+ workers, meets monthly at mines (R. 14) |
| Welfare Officer | 500+ workers | 250+ workers (R. 57) |
| Medical records | kept ten years | employment + five years, held by the manager (R. 114(1)) |
| Periodic medical exam | interval not stated | annually, FORM-IX (R. 109(1)(ii)) |
| Registers | Forms A, B, D, E, K | FORMS XIII, XIV, XV, XIX, XX; electronic allowed, kept 5 years |
| Accident notice | Form J | FORM-XI: death forthwith, injury and dangerous occurrence within 12 hours (R. 7) |
| Rescue refresher | quarterly | as ordered by the Chief Inspector-cum-Facilitator (R. 141(2)) |

One old citation was wrong even under the old law: "Medical records retained for ten years" cited Mines Rules R. 29-K, which constituted the Appellate Medical Board.

## What the migration touched

- **Clauses:** 28 rewritten and re-embedded (MiniLM), so Rulebook retrieval matches the new wording. Version `2026-09-16`.
- **Duties:** 74 migrated and 3 corrected in place (title, owner, frequency, evidence type). A duty whose title had been edited by hand keeps its title. 21 new duties were created for the added clauses at every mine each clause applies to.
- **Evidence:** untouched. The hash chain covers obligation ids, not clause text; it was verified intact for all three mines before and after.
- **Returns:** the `MINES_RULES_ANNUAL` return scope became `OSH_ANNUAL` (OSH Code 2020 + OSH (Central) Rules 2026).

Clause text is a close reading of the cited provision, shortened for the app. It is not verbatim Gazette text; check the Gazette before relying on a duty.
